- Правила для ИИ-агента: [AGENTS.md](AGENTS.md)
- Внутренние решения, планы и вводная для нового чата — в проекте «электромонтаж» в Claude (не в репозитории: он публичный)
- Боевой сервер: [docs/server.md](docs/server.md)
